# Overseer

This repository is basically a fork from [ProductivityApp](https://github.com/Meta-Dusk/productivity-app), specifically version **0.5.0**. The reason being, is that this project will basically have the same functionalities from the parent repository, but with more customizability, focusing more on the _funny_ aspects.

This app's existence, is for a friend of mine. A gift, I must say.

## Feature List

| Feature | Description | Version |
| ------- | ----------- | ------- |
| **Desktop Activity Monitoring** | The app will attempt to monitor if you're doing productive things or not. | v0.2.4 |
| **Customizable Behavior** | The app's certain behaviors can be configured to fit your likings. | v0.2.4 |
| **Lore** | A vague story will be included for the _events_ happening in the app. | v0.2.4 |
| **Jumpscares** | The app will attempt to _jumpscare_ you. | v0.2.5 |
| **Window Effects** | The app's window can perform various graphical effects. | v0.2.5 |
| **Sounds** | Sounds may include various SFXs and Music. | v0.2.5 |

## Setup / Installation

You'll be downloading the installer located at the right side of the repo, the "Releases" tab, where you can download the latest version. Please refer to the download instructions listed there.

## Concerns

If you're having second thoughts about the security of this app, don't worry, as everything this app does is only for appearance. An example behavior (where you would think is a bit suspicious) would be the native Windows message box popups. Don't worry, they are only there for mild _scares_.
As for the files getting created in the desktop, they are deleted once you close the app, so you don't even have to delete them manually. All files created by the app are handled this way, so you can rest easy.
Now if the **Window Effects** feature of the app also concerns you, don't worry, as it will also reset automatically if you close the app, and it can also be reset if you start doing "productive" things.
