# Overseer

This repository is basically a fork from [ProductivityApp](https://github.com/Meta-Dusk/productivity-app), specifically version **0.5.0**. The reason being, is that this project will basically have the same functionalities from the parent repository, but with more customizability, focusing more on the _funny_ aspects.

This app's existence, is for a friend of mine. A gift, I must say.

## Feature List

| Feature | Description | Version |
| ------- | ----------- | ------- |
| **Customizable Behavior** | The app's certain behaviors can be configured to fit your likings. | _Not implemented yet_ |
| **Jumpscares** | The app will attempt to _jumpscare_ you. | _Not implemented yet_ |
| **Window Effects** | The app's window can perform various graphical effects. | _Not implemented yet_ |
| **Desktop Activity Monitoring** | The app will attempt to monitor if you're doing productive things or not. | _Not implemented yet_ |
| **Sounds** | Sounds may include various SFXs and Music. | _Not implemented yet_ |
